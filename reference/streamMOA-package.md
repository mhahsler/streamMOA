# streamMOA: Interface for MOA Stream Clustering Algorithms

Interface for data stream clustering algorithms implemented in the MOA
(Massive Online Analysis) framework (Albert Bifet, Geoff Holmes, Richard
Kirkby, Bernhard Pfahringer (2010). MOA: Massive Online Analysis,
Journal of Machine Learning Research 11: 1601-1604).
